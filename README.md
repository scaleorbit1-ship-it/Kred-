# 🛡️ Remix KRED — AI-Powered Sovereign Credential Wallet & Intelligent Document Synthesis

> **Securely store, organize, understand, and assemble application packages from your critical credentials, IDs, certificates, and records with sovereign AI intelligence.**

---

## 📌 Project Overview
- **Project Title**: **Remix KRED** (*AI-Powered Sovereign Credential Wallet & Intelligent Document Synthesis Platform*)
- **Tagline**: Sovereign Client-Side Encrypted Credential Intelligence, Autonomous Clarification Questioning, and Executive Document Canvas.

---

## 🎯 Target Audience

1. **Students & University Applicants**:
   - Preparing university admissions, scholarship dossiers, statements of purpose, and personalized study roadmaps.
   - Requiring degree equivalency audits (WES, UK ENIC, ECTS) and interactive study flashcards.

2. **Job Seekers & Global Professionals (Engineers, Designers, Researchers)**:
   - Generating tailored, ATS-compliant technical CVs/Resumes and Product Design case studies.
   - Assembling certified credential portfolios and verifiable cover letters.

3. **Freelancers & Independent Agencies**:
   - Creating itemized client invoices, payment receipts, attestation certificates, and official business letterheads.

4. **Founders & Entrepreneurs**:
   - Generating 16:9 executive pitch decks and investor presentations.

5. **Educators & Certifying Bodies**:
   - Issuing verified certificates of completion with cryptographic audit hashes.

## 💻 Tech Stack Used

| Category | Technologies / Libraries |
| :--- | :--- |
| **Frontend Framework** | **React 19**, **TypeScript** (strict type safety, modular hooks) |
| **Styling & Design System** | **Tailwind CSS v4**, `@tailwindcss/vite`, Custom CSS tokens, Responsive viewports |
| **Icons & UI Effects** | **Lucide React**, **Motion (Framer Motion)**, **Canvas-Confetti** |
| **Markdown Rendering** | **Marked** (real-time Markdown to HTML synthesis) |
| **Backend / Server** | **Express.js 4**, **Node.js**, **tsx** (TypeScript execution engine) |
| **Build & Bundler** | **Vite 8**, `@vitejs/plugin-react` |
| **AI & Neural Intelligence** | **Google Gen AI SDK** (`@google/genai` with Gemini 2.5), **NVIDIA NIM API** (`llama-3.3-70b`, `nemotron-70b`, `qwen2.5-72b`, `deepseek-r1`) |
| **Autonomous Workflow** | Multi-step interactive clarification question engine & intent classifier |
| **Web Grounding** | Real-time DuckDuckGo search integration for up-to-date credential standards |
| **Security & Cryptography** | Web Crypto API (`AES-256-GCM`), Local-First Storage (IndexedDB/LocalStorage) |
| **Cloud Database & Auth** | **Firebase 12** (`firestore`, `auth`, `app`) |
| **Document Canvas** | Interactive preview canvas for Flashcards, CVs, Certificates, Invoices, Slides, and Letterheads |
